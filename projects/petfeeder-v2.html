Smart PetFeeder v2

ESP32-based smart pet feeder enabling remote pet feeding through Firebase-connected mobile applications with real-time command execution.

ESP32 · Firebase RTDBReact Native (Expo)FlutterFlow · Fusion 360Status: Ongoing

Problem

Pet owners need a reliable way to feed pets remotely and on schedule. Existing solutions are often closed, expensive, or lack real-time feedback on whether a feeding actually occurred.

Design decisions

  • ESP32 + servo-driven auger for physical dispensing — the auger mechanism is evaluated in Fusion 360 before hardware commitment.
  • Firebase Realtime Database as the bridge between mobile app and firmware, enabling real-time command execution without constant device polling.
  • React Native (Expo) rebuild — moving from FlutterFlow to Expo for a more maintainable, code-first mobile app with improved UI.
  • Secrets kept out of source control — Firebase credentials live in a gitignored Secrets.h.

Implementation

  • ESP32 Arduino firmware connects to WiFi and Firebase RTDB, reads feed commands, and drives an SG90 servo to dispense food.
  • Initial FlutterFlow app achieved end-to-end functionality; the Expo rebuild is in progress with Firebase and device integration.
  • Firmware currently uses polling (planned: streaming) and blocking delay() (planned: non-blocking state machine).

Technologies

ESP32Firebase Realtime DatabaseReact Native (Expo)FlutterFlowFusion 360Arduino IDE

Outcomes & status

Ongoing work — not yet complete. The firmware sketches connect to WiFi and Firebase RTDB and drive a servo, but the Expo app does not yet read or write live Firebase data. Firmware and app database schemas do not currently match. A status LED is planned.
